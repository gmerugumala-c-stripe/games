# Checkers Game

A beautiful, fully-featured Checkers game built with vanilla HTML, CSS, and JavaScript.

## Features

- **Classic Gameplay**: Traditional checkers rules with all standard moves
- **King Promotion**: Pieces become kings when reaching the opposite end
- **Mandatory Jumps**: If a jump is available, you must take it
- **Multi-Jump Support**: Chain multiple captures in a single turn
- **Move History**: Track all moves made during the game
- **Undo Functionality**: Take back moves if needed
- **Sound Effects**: Audio feedback for moves, captures, and promotions
- **Responsive Design**: Works on desktop and mobile devices

## How to Play

1. **Open** `index.html` in your web browser
2. **Red moves first** - click on a red piece to select it
3. **Valid moves** appear as green dots on the board
4. **Click a destination** to move your piece
5. **Capture pieces** by jumping over them diagonally
6. **Become a king** by reaching the opposite end of the board
7. **Win** by capturing all opponent pieces or blocking their moves

## Rules

- Pieces move diagonally forward only
- Kings can move diagonally in any direction
- Captures are mandatory - if you can jump, you must
- Multiple jumps in a single turn are allowed (and required if available)
- Game ends when one player has no pieces or no valid moves

## Controls

- **New Game**: Start a fresh game
- **Undo**: Take back the last move
- **Sound**: Toggle sound effects on/off

## Technologies Used

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox, Animations)
- Vanilla JavaScript (ES6 Classes)
- Web Audio API for sound effects
- Google Fonts (Playfair Display, Source Sans 3)
