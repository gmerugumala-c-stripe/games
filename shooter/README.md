# Target Blitz - Shooting Gallery Game

A fast-paced shooting gallery game with multiple weapons and target types.

## How to Play

1. Open `index.html` in a web browser
2. Click "START MISSION" to begin
3. Shoot targets by clicking on them
4. Avoid shooting danger targets (red) - they deduct points!
5. Build combos by hitting consecutive targets
6. Survive 60 seconds and get the highest score!

## Weapons

| Weapon | Damage | Fire Rate | Ammo | Special |
|--------|--------|-----------|------|---------|
| **Pistol** | 1 | Fast | 30 | Reliable all-rounder |
| **Shotgun** | 3 | Slow | 8 | 5-shot spread pattern |
| **Rifle** | 2 | Medium | 20 | High precision |
| **SMG** | 1 | Rapid | 50 | Slight spread, fast fire |

## Target Types

- **Standard (Blue)** - 10 points × combo multiplier
- **Fast (Purple)** - 25 points × combo multiplier, moves faster
- **Bonus (Gold)** - 50 points × combo multiplier, sparkles!
- **Danger (Red)** - AVOID! -30 points, requires 2 hits to destroy

## Controls

| Key | Action |
|-----|--------|
| **Click** | Shoot |
| **1-4** | Switch Weapon |
| **R** | Reload |
| **Space** | Start/Pause |

## Scoring System

- Base points depend on target type
- Combo multiplier increases with consecutive hits (max x10)
- Missing a shot resets your combo to x1
- Final accuracy is tracked for bragging rights!

## Tips

- Use the SMG for fast targets
- Shotgun is great for clustered targets
- Don't forget to reload before you run out!
- Aim for bonus targets to maximize score

## Browser Support

Works in all modern browsers (Chrome, Firefox, Safari, Edge).
