## 🎮 Gameplay Enhancements

### Survival Mode Improvements

- [ ] Targets that escape off-screen cost a life

### New Game Modes
- [ ] **Challenge Mode** - Complete specific objectives (e.g., "Get 5 critical hits", "Reach x10 combo")
- [ ] **Boss Rush** - Fight bosses back-to-back with minimal breaks
- [ ] **Zen Mode** - No time pressure, relaxing target practice
- [ ] **Hardcore Mode** - 1 life, no power-ups, max difficulty
- [ ] **Daily Challenge** - Seeded random mode with global leaderboard

### Difficulty Settings
- [ ] Easy / Normal / Hard / Nightmare presets
- [ ] Custom difficulty sliders (speed, spawn rate, target mix)
